# Zona Cero — Battle Royale Enhanced

Mini battle royale en un solo archivo HTML (`index.html`).

## Cómo jugar

Abre `index.html` en cualquier navegador moderno.

## Características

- **Lobby** con selección de clase, mapa, dificultad y modo de juego
- **4 clases**: Asalto, Médico, Ingeniero, Sombra (cada una con habilidad única)
- **8 armas** incluyendo francotirador, ametralladora y lanzacohetes
- **Habilidades**: Dash (F), Granada (G), Habilidad de clase (Q)
- **3 mapas**: Isla, Ciudad, Desierto
- **Minimapa**, números de daño, suministros aéreos, torretas, ranking local
- **Modos**: Clásico, Blitz, Hardcore

## Controles

| Tecla | Acción |
|-------|--------|
| WASD | Mover |
| Shift | Correr |
| Mouse | Apuntar / Disparar |
| R | Recargar |
| E | Recoger |
| Q | Habilidad de clase |
| F | Dash |
| G | Granada |
| 1-5 | Cambiar arma |
| Esc | Pausa |
