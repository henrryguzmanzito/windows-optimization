# NEÓN PURGA — Battle Royale

Mini battle royale cyberpunk en un solo archivo HTML.

## Jugar

Abre `index.html` en cualquier navegador moderno.

## Controles

- **WASD** — Mover
- **Shift** — Correr
- **Click** — Disparar (empiezas con pistola)
- **R** — Recargar
- **E** — Recoger suministros
- **Q** — Habilidad de clase
- **F** — Dash
- **G** — Granada
- **1-5** — Cambiar arma
- **Esc** — Pausa

## Características

- Temática cyberpunk/neon con efectos visuales
- Lobby + despliegue rápido
- 4 clases, 8 armas, 3 mapas
- Tormenta tóxica, suministros aéreos, drones, rachas de kills
- Ranking local
